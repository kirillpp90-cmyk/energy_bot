# ⚡ КиловаттБот

Telegram-бот для расчёта энергопотребления и стоимости электроэнергии.

## Возможности

- **`/calc`** — точный расчёт через пошаговый диалог (FSM): мощность прибора → часы работы в день → количество дней. Валидация ввода, анимация процесса расчёта, учёт персонального тарифа пользователя.
- **`/quick`** — быстрый расчёт по типу жилья (квартира/дом и т.д.) с погрешностью ±15%.
- **`/tariff`, `/set_tariff`** — просмотр и изменение тарифа на электроэнергию (валидация 0–50 руб/кВт·ч).
- **`/mydevices`** — сохранённые приборы пользователя: просмотр, удаление, массовый расчёт всех приборов сразу.
- **`/help`** — обращение в поддержку: пересылка любого типа контента через `bot.copy_message()`.
- **`/admin`** — панель администратора: статистика, рассылка сообщений всем пользователям, постраничный список пользователей (10 на странице) с защитой от спецсимволов в именах.
- **`/start`, `/about`, `/menu`** — регистрация и базовая навигация.

## Стек

- **Python** 3.12
- **aiogram** 3.27 — Telegram Bot API framework
- **aiosqlite** 0.22 — асинхронная работа с SQLite
- **SQLite** — хранение пользователей и приборов

## Структура проекта


## База данных

**users**: `user_id`, `username`, `first_name`, `last_name`, `tariff REAL DEFAULT 5.5`

**devices**: `id`, `user_id`, `name`, `power_watt`, `hours_per_day`, `days`

## Особенности реализации

- Ручное открытие/закрытие соединений с БД (без `async with`)
- `asyncio.Lock()` на все операции записи для предотвращения гонок
- `row_factory = aiosqlite.Row` в функциях чтения
- Автоматическая миграция схемы БД при обновлении (добавление недостающих колонок)

## Запуск

```bash
pip install -r requirements.txt
```

Указать токен бота в `config.py`, затем:

```bash
python main.py
```
